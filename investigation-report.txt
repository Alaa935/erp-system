========================================
التقرير النهائي - أين تختفي البيانات
========================================

1. مشكلة search=undefined (مؤكدة عملياً):
----------------------------------------
useCustomers({ search: debouncedSearch || undefined })
debouncedSearch = "" initial state
"" || undefined = undefined (عشان "" falsy في JS)
params1 = { "search": undefined }

Object.entries({ search: undefined }) → [["search", undefined]]
url.searchParams.set("search", undefined) → "?search=undefined"

تم التأكيد بإستخدام Node.js:
  URL with undefined: https://server-e6y4.onrender.com/api/customers?search=undefined
  URL with empty string '': https://server-e6y4.onrender.com/api/customers?search=

الفرق: undefined يصبح string "undefined" ويبحث في Prisma عن:
  WHERE (name ILIKE '%undefined%' OR phone ILIKE '%undefined%')
  → 0 results

2. Suppliers نفس المشكلة بالضبط:
--------------------------------
useSuppliers({ search: "" || undefined })
→ نفس الـ undefined → ?search=undefined

3. Sales Reps لا يوجد search parameter:
---------------------------------------
useSalesReps() → /api/sales-reps بدون أي params

  → الفلتر يخفي الكل → items = [] → 0 rows
